# StockPulse AI - Indian Stock Review Platform

An AI-powered platform for analyzing and tracking Indian stocks with real-time NSE/BSE data, AI recommendations, portfolio tracking, and advanced financial insights.

## 🎯 Features

- **AI Stock Recommendations** - Buy, Hold, Sell predictions powered by AI analytics
- **Real-Time NSE/BSE Data** - Live market charts and watchlists
- **Portfolio Tracking** - Profit/loss analysis and portfolio insights
- **Admin Dashboard** - Manage users, subscriptions, and analytics
- **Dark Fintech UI** - Modern interface optimized for mobile and desktop
- **AI News Sentiment** - Market intelligence from news sentiment analysis

## 🛠️ Tech Stack

- **Frontend**: React 18 + Vite
- **Styling**: Tailwind CSS
- **Deployment**: Vercel
- **Build Tool**: Vite

## 📦 Installation

```bash
git clone https://github.com/hamidabdullah9-blip/stockpulse.git
cd stockpulse
npm install
npm run dev
```

## 🚀 Deployment

Automatic deployment to Vercel on push to `main` branch.

**Live**: https://stockpulse-lyart.vercel.app

## 📝 Scripts

- `npm run dev` - Development server
- `npm run build` - Production build
- `npm run preview` - Preview build
